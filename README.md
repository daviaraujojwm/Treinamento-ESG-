# Painel EcoVadis em Streamlit

## Como executar

1. Instale o Python 3.10 ou superior.
2. Abra o terminal na pasta deste projeto.
3. Instale as dependências:

   `pip install -r requirements.txt`

4. Inicie o painel:

   `streamlit run app.py`

## Como enviar a planilha

Ao abrir o painel, use o botão **Selecionar planilha Excel** na área principal da página e escolha o arquivo `.xlsx`. O painel processará a planilha e atualizará os indicadores.

O upload fica no painel principal (não escondido na barra lateral). A planilha é processada em memória pelo aplicativo.
